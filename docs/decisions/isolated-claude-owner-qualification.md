## Minimum experiment and refusal/settlement proof

Prepare one immutable assignment, retain its original private handoff and claim
once. Spawn only the source-owned gated bridge, register that original child
durably, establish capture, then deliver Start. Recheck caller/root/binary/
configuration before the bridge's fixed exec. No vendor may initialize before
that gate. Verify only reviewed stdio descriptors survive the bridge/exec chain;
no new inherited control descriptor is implicit. Any
mismatch before this invocation attempts spawn is local pre-attempt refusal; it
says nothing about a different or earlier attempt.

Before the vendor, use the exact same-profile fixed safety preflight to establish
inside/outside read, fork/posix_spawn denial, allowed versus denied loopback routes
and quiet unselected listeners. Run the bounded version phase and require matching
binary bookends before the single scripted protocol child. No additional endpoint,
security exception, timeout extension or retry is automatic.

Require the nonce text witness before exactly one successful terminal record,
correct session/attempt binding, no tools or later activity, zero exit, empty
stderr, lossless capture, both physical pipe EOFs, reconciled input/FIFO, and both
original child wait results. Compare the live owner's byte commitment against the
exact persisted raw extent under current source/store validation. Independently
settle the local server as completed and prove denied listeners quiet. A final
qualification receipt is issued only after all witnesses agree.

Any partial send, missing acknowledgment, uncertain identity, deadline, raw rewrite,
source change, pending writer, capture loss or unsettled actor leaves the result
unknown/refused and retains claims/root evidence. Later quietness cannot fabricate
a lost private receipt or permission to replay. Cleanup requires original-child
settlement, reader join, channel/server settlement and exact root ownership;
otherwise retain the isolated evidence. No universal bounded-kill guarantee is
claimed.

A successful result still would not qualify real-provider authentication, tools,
live input/resume, arbitrary caller/grants, complete runtime closure, descendant
containment, production numeric envelopes, another backend/platform, publication
or production launch. Those remain separate material gates.
