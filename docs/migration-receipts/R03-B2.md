## Design review and implementation provenance

Fresh native plan review and separate descriptor feasibility consultation accepted
single-thread fixed composition with refinements: a dedicated fresh parent mode,
not Cargo's multithread test process; close every Store before spawn; reject unknown
ambient descriptors and environment; unbuffered finite pipes; one absolute local
deadline; complete Prepared+EOF can authorize despite parent death; structural
post-spawn cleanup; finite inert child safety before owner-death tests; qualified
nofollow ledger. Primary accepted these before code.

Sol low implemented pure values/codec/validation and concrete platform adapters;
primary integrated additional private frame types, fixed host composition,
dependency policy, docs and independent verification. Dedicated Luna medium owns
pure codec/application/platform/policy tests; another Luna medium owns OS fixture
qualification and independent raw read-only SQLite/effect oracles. No external
backend delegation. Usage totals unavailable.

The actual scoped launch ordering is parent prepare/drop Store/spawn owner;
owner validate/claim/drop Store/spawn child; persist exact registered child/drop
Store; Start; independent fixed child probe/open/write/drop Store/ledger fsync;
EffectDone; acceptance commit/drop Store; Accepted. Every post-spawn failure passes
through retained sole-waiter cleanup. Reservation release is never called.

Frame/context checks bind actual owner PID/start/boot, operation, generation,
digest, full immutable request, nonce/revision and exact durable acceptance. Child
Start additionally binds the full owner fence; the child validates expected root
generation, exact SpawnObserved row/fence and its actual self identity before the
fixed effect. Fixture nonce is nonsecret concurrency context, not authentication.
No responder credentials or original prepared payload are passed to the child.
