## Reviewed design and delivered mechanism

[Ownership protocol](../ownership-foundation.md) records exact internal transitions,
rights, fences, proofs, bounds and schema evolution. Fresh native plan review
accepted the scope with refinements: parse/encode actual marker schema, reverify
stored payload SHA-256 in the snapshot, persist complete bound release evidence,
keep drain separate from history loss, and preserve truthful post-commit outcomes.
Primary accepted these before implementation.

Native gpt-6.1-sol low owns production domain/application/storage code; dedicated
gpt-6-luna medium owns sequential/value/policy tests, with a supplemental Luna
medium writer for independent actor/atomicity tests. Primary owns adjudication,
exact dependency/schema/policy integration, docs, independent verification and local
delivery. No external backend or nested workflow; usage totals unavailable.

Pure IDs/digest/request/phase/owner/fence/proof values feed constructor-injected
application ports. Storage verifies incoming SHA-256 before admission and stored
bounded payload SHA-256 on materialization, then uses short IMMEDIATE transactions,
unique reservations/attempt history/live sessions and conditional revision updates.
Only the first Prepared-to-Claimed CAS returns Granted. Existing/replayed claims,
snapshots and refreshed fences never mint another right. Claimed without a child
observation remains effect-possible. No leases, reclaim, reset or auto replay.

A child binds once before AcceptanceRecorded, which is an internal durable marker
before acknowledgment, not proof of peer delivery. Cancellation is sticky intent,
not a signal or release proof. Release requires exact current context and either
cancelled-unclaimed DB evidence, positive NeverStarted/owner-dead fixture evidence,
or exact terminal child/owner-dead/drain/containment fixture evidence. Capture loss
is retained independently. Every released observation validates the persisted
private audit against full bound context. These are supplied trusted fixture
facts, not authentication of a nonchild or real cleanup qualification. R03-A's
Unknown containment cannot supply positive terminal release proof.

Fresh SQLite schema2 is deliberate. Actual marker schema2 and ownership namespace
version1/generation are validated. Schema1/future/mismatched roots refuse; no
migration, read initialization or adoption. Existing lock hierarchy, WAL/FULL/FK,
explicit recovery, disabled auto/close checkpoints and64MiB qualification remain.
Primary self-review additionally made ownership metadata generation checks exact
in UTF8 bytes, so embedded NUL cannot hide an oversized suffix, and exposed actual
preflight SQL constants for independent runtime allocation-bound observations.
