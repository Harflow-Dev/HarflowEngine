## Delivered cells and limitations

Domain/application/storage now expose an internal typed event query and fixture-only
read session. Optional event tables are created only by new fixture initialization;
old/missing/future schemas refuse. Reads resolve the task and read stream generation,
page and facts in one transaction. Named start/end indexes seek logical boundaries;
metadata projections and length checks precede retained-body allocation. Filtered
bodies are not loaded. Page work is bounded by the logical1MiB window, decoded limit,
configured Store limits and internal262144-byte accounting. This is not a public
serialized producer or measured performance result.

Typed cursors carry task/store/stream/filter, direction/boundary/resync and neighbor
sequence/skip context. Append preserves generation for readable streams, including
empty polling and completion of withheld partial tails. Explicit replacement or
unavailability expires continuity. Lookup and unreadable-log results stay distinct.
Cursor contents are checked after task resolution; usage conflicts precede authority,
which precedes every repository call. DirectFixture is an injected trusted test grant,
not a caller-request flag or production verifier.

Capture, drained, recorded status and grace are independent inputs. EOF completion
is derived from the actual classified last task_finished record at complete EOF,
independent of the page filter. Final does not assert gap-free/complete history.
Stored status does not imply ownership, capture or terminal drain.

Interfaces provide strict consumer-only ctl/event views and a bounded raw fixture
normalizer using existing serde_json. Outer current release-line validation does not
reject syntactically valid historical inner event writer versions. Unknown fields,
kinds, states and missing/null/value distinctions survive. Default/all use the fixed
known-kind set: unknown kinds are accounted but filtered by the internal reader.
Projection applies bounded strings/lists/depth and oversized stubs.

Trust and omissions are explicit: normalized fixture bodies assert consistency with
seq/kind metadata; partial-tail append asserts raw-prefix preservation because raw
bytes are not stored. No live ingestion/integrity proof follows. Internal seq/offsets
fit signed64-bit SQLite, kinds128UTF8bytes/status256UTF8bytes. Strict JSON and exotic
numeric formatting are not full Python parser/serialization parity. No public cursor
encoding/authentication, sampled observed_at/change_token, CLI usage/error serializer,
retention scheduler, caller OS verification, producer fitting or watcher is delivered.
Consumer byte limits bound received documents only.
