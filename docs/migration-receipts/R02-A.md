  member inventory, dependency kind, lint, file-size and domain guards. Tests reject
  unknown owners, extra features/defaults, nonexact version and dev/optional/renamed/
  target-specific edges. Workspace unsafe and production panic/unwrap/expect rules

- Dedicated test writer owns independent SQLite/raw file/lock and policy oracles.
  No host/transport, source runtime, app adapter or public error semantics changed.

Fresh plan review required separate no-touch qualification, atomic absent-root
creation, one deadline/no late effects and typed batches rather than effectful
closures. Primary accepted these refinements. A raw WAL parser proposal was rejected:
it could not close an append-after-scan race and duplicated SQLite framing logic.
Instead R02-A uses a lifetime exclusive Store claim/shared probe and refuses nonempty
residual WAL before SQLite access. No automatic checkpoint or recovery is invented.

This is deliberately narrower than final multi-owner storage readiness. Active-owner
probe/open returns Busy; shared callers use one Store handle. Live multiprocess
reopening, shared qualification/checkpoint scheduling and crash-WAL recovery require
separate implementation/proof before detached execution relies on the store. External
raw SQLite writers bypassing the cooperative lock protocol are not supported schema
changers. Symlink/inode checks reject observed replacement, not atomic hostile path
races. Windows binding refuses; Unix tests do not qualify Windows or later Linux.
