## State transitions and guarantees

Initialization: nonexistent root -> exclusive lifecycle/I/O -> SQLite schema and
random generation commit -> completed initial TRUNCATE -> exact marker publication.
An incomplete/missing marker or new I/O lock refuses; there is no silent old-fixture
upgrade. Shared handles pin root/schema/generation and use mutex->I/O admission for
writes. Probe: shared lifecycle + I/O -> private bounded main/WAL copy -> SQLite
logical/integrity qualification -> private cleanup, without source SQLite access.
Open: same qualification -> explicitly authorized source WAL-index recovery/open.
Explicit recovery: exclusive lifecycle + I/O -> qualification -> SQLite TRUNCATE.
PASSIVE checkpoint returns busy/frame/completeness evidence without forcing readers.
No schema mutation is implemented; only its exclusive lifecycle rule is specified.

Source auto/last-close checkpoints are disabled before SQL access; final-close tests
compare main and WAL bytes exactly. This plus gated mutation/open/checkpoint permits
a stable main+WAL copy; source SHM is never copied. All writers must honor protocol.
No custom WAL parser, unconditional sidecar removal, state reset or replay exists.
Fresh deadline checks precede source opening, checkpoint and marker publication;
no queue survives admission failure. SQLite/OS calls cannot be preempted mid-call.

## Fault and performance limits

macOS arm64/local cooperative filesystem evidence only, not platform/hosted-CI
qualification. No device power loss, directory-fsync durability, arbitrary I/O/
disk-full faults, corrupt ignored-WAL-frame detection, or instruction-level SQLite
interruption is proved. SQLite decides which committed frames are valid; quick_check
cannot certify every damaged/uncommitted tail. External raw schema mutators bypassing
gates and hostile same-user path races are excluded. Root/lock/marker symlinks and
observed inode replacement refuse; no atomic hostile nofollow claim is made.

Snapshots cap main+WAL at64MiB and copy in bounded chunks with deadlines. Whole-store
copy/quick_check costs, automatic checkpoint scheduling, WAL-growth policy and final
scale/performance budgets are not qualified. A legitimate larger store fails closed
rather than silently bypassing qualification. These are explicit internal-foundation
limits, not changed R01 thresholds or evidence that50ms/20ms targets passed.
