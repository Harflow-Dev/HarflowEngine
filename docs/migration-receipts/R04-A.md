## Delivered foundation

See [recovery observation](../recovery-observation.md) for exact APIs and guarantees.
The application inspector receives operation-scoped storage, identity and raw ports.
It returns historical interval evidence and Retained reservation disposition, never
a process-control or replacement grant. Released records are explicitly refused.

The storage adapter acquires source claims/I/O admission, copies bounded main+WAL,
opens SQLite only on the private copy, and cleans that copy. Existing Store readers
retain their interfaces through a narrow read context. Two selected snapshots compare
complete ownership/capture values, physical source identities/generation and SHA256
of every validated private event. Event chains require contiguous revisions,
monotone offsets/EOF/loss, valid immutable terminal and exact final row equality.
Metadata duplicate checks use LIMIT2; event reads use LIMIT129 and refuse beyond128.
Integer projections reject malformed large cells before decoding/materialization.
No source SQLite open/configuration, checkpoint, source SHM creation or repair occurs.

The separate macOS identity port distinguishes matching non-zombie Present, Zombie,
positive original absence, PID reuse, boot change and Unknown. Stable validated kernel
boot samples surround each probe. Existence probes send no signal. The original
IdentityPort's missing lookup remains Unknown. No observation gives another process's
retained waiter or control rights, and no absence synthesizes exit/drain/containment.

Raw observation is read-only metadata at fixed operation-derived filenames. It checks
regular single-link shape, exact device/inode and indexed/observed length bounds with
stable open/path metadata. A65536byte cap applies to each stream (131072both); no raw
payload is copied. Missing/replaced/truncated/unreadable sources cannot qualify a
terminal extent. Unindexed tails retain unknown sync provenance. A recorded terminal
extent is qualified only against existing indexed exit/bothEOF/noLoss/event history
and exact observed raw extents, with no public success or release mapping.

The inspector repeats raw metadata as a bookend and rejects changed evidence without
retrying. Its deadline is min(caller,start+2seconds); each snapshot main+WAL cap64MiB,
two-copy total work cap128MiB, copy buffer64KiB, existing record allocation budgets.
Synchronous filesystem/kernel/SQLite work is nonpreemptible; these are admission/work
bounds, not hard wall-clock, RSS, p99 or scale qualification. Locks can cause Busy for
inspectors or cooperating writers. Reports cannot promise atomic OS/filesystem/database
truth or persistence after their last sample.
