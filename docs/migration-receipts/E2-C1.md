# E2-C1 — drainable Claude NDJSON foundation

This internal codec foundation adds `hf_interfaces::claude_ndjson`. It is not
connected to an executable, provider, host command or public execution route.
It grants no permission, correlation, authenticated session or settlement authority.

`Decoder::new` validates a copied immutable `Limits`. `feed` consumes at most
4096 bytes and stops at the first LF, returning at most one event. The caller
retains the untouched remainder. A malformed line consumes through its LF; line
overflow consumes through the first offending byte. Faults clear pending bytes,
remain sticky and consume zero on later calls. No whole trace, output queue or
run-wide byte counter is retained. `pending_bytes` exposes retained length.

`finish` accepts empty physical EOF without requiring a terminal record. A partial
line gives sticky `Truncated`; finish is idempotent. Clean finish closes the wire.
A terminal event does not close it or establish a semantically accepted outcome.
The constructor's attempt identifier is supplied provenance only.

Provisional internal ceilings are 1 MiB of raw line excluding LF, 1 MiB of dynamic
normalized payload per event, 128 records, 16 container levels (root counts as 1),
256 identifier bytes, 4096 decoded key bytes and 128 members per object/array.
Every limit may be injected smaller, but must be nonzero and at most its ceiling.
These are not accepted vendor production budgets. Dynamic bytes include every
returned string occurrence: repeated attempt/session/parent identifiers and each
text/tool identifier. Fixed enum/vector overhead is bounded separately.

The strict reader checks UTF-8, JSON grammar, trailing data, decoded duplicate
keys, key sizes, container depth and collection sizes. Unknown event/content
shapes refuse. Known malformed fields refuse; system/result effect-bearing
shapes retain the conservative unsupported classification of the offline codec.
The separate existing offline decoder and fixture JSON parser are unchanged,
including their original budgets and error mappings.
